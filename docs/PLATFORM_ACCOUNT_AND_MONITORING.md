# 平台账号与监控更新说明

本文说明当前版本中视频号助手登录、本账号数据隔离、视频详情和监控中心的使用方式。

## 1. 启动

### Windows 运行包

在运行包目录执行：

```powershell
.\scripts\windows\Start-Insight-Preview.cmd
```

启动器会运行 API、scheduler 并打开 Insight 页面。默认地址为 `http://127.0.0.1:18081/`。

### 源码运行内置 Edge

先启动 API，再在项目根目录启动项目自带的 Edge 桌面壳：

```powershell
node desktop\insight_desktop.mjs
```

桌面壳使用独立浏览器配置和 DevTools 通道，不会打开外部微信客户端窗口。需要已安装 Microsoft Edge；API 默认使用 `http://127.0.0.1:18081`。

当前 Windows 运行包的启动脚本负责 API 和 scheduler；如果需要源码内置 Edge 登录能力，应从源码目录启动桌面壳，或在打包时把 `desktop/insight_desktop.mjs` 纳入桌面启动器。

## 2. 登录视频号助手

1. 打开左侧“平台账号”。
2. 确认桌面壳已连接后，点击“在内置浏览器中登录”。
3. 在内置 Edge 中打开的视频号助手页面完成加载。
4. 使用手机微信扫描内置浏览器中微信官方登录页显示的二维码，并在手机确认。
5. 登录成功后，平台账号页显示当前登录账号和连接设备。

登录状态来自内置 Edge 的真实页面状态。没有 Edge 连接、页面未就绪或登录已失效时，页面会显示对应状态，不会用演示数据替代。

平台账号页不再抓取、生成或展示二维码，也不再嵌入独立的 OAuth iframe。已有登录窗口会复用并激活，使用同一个持久浏览器配置；打开失败会显示实际错误，不会提前提示成功。

## 3. 查看本账号数据

登录后点击“采集本账号作品”。采集结果会写入当前 Insight 工作区，并出现在平台账号页的“本账号数据”区域。

本账号区域包含：

- 账号指标和账号画像；
- 当前账号的视频列表、发布时间和互动指标；
- 评论库、历史证据和监控状态；
- 当前账号关联的监控任务。

平台账号页只展示当前登录账号。切换登录账号后，旧账号的数据区域会清空并重新读取新账号的数据。

点击“刷新本账号数据”只重新读取已保存的 Insight 数据；点击“采集本账号作品”才会通过内置 Edge 读取视频号助手并写入新的作品数据。

## 4. 查看视频详情

在“本账号数据 → 视频列表”中点击视频标题，可在当前平台账号页打开独立的视频详情区域。详情包含当前指标、历史变化、原始评论和视频预览状态。

点击“返回上一页”回到本账号数据，不会改变全局路由，也不会跳转到“视频分析”。视频详情嵌入账号页时不会自动触发过期指标采集；需要更新指标时可使用详情页的“刷新详情”或“立即采集指标”。

## 5. 监控中心

“监控中心”位于“账号监控”上方，用于查看全局监控状态：

- 调度器是否在线、最近心跳和状态更新时间；
- 已启用任务、正在运行任务、失败/逾期任务；
- 已配置的监控目标和已覆盖的数据来源；
- 最近运行活动和任务运行历史。

点击“新建监控任务”创建周期任务。没有任务时，调度器在线只表示服务可用，不表示正在采集；只有存在实际运行中的任务时才显示“正在采集”。

最近活动中的任务可以直接点击，页面会滚动到对应任务的运行历史。暂停、恢复、立即运行、重试和归档仍在任务卡片中完成。

## 6. 刷新规则

- 未登录时每 5 秒检查一次连接，已登录时每 15 秒检查一次轻量会话状态，以便发现退出、断开和账号切换。请求串行执行，离开页面时取消请求并停止检查。
- 会话检查不重复读取已成功查询过的本账号作品数据；“刷新连接”和“刷新本账号数据”保留手动操作。
- 账号切换或退出后清空旧账号数据和采集统计；旧账号尚未完成的采集结果不会回填到新账号。
- 监控中心会刷新调度状态和任务运行信息，用于及时显示失败和逾期任务。
- 缺失指标仍显示为不可用状态，不会被自动改成 `0`。
